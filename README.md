## 관심 분야

- XAI (설명 가능한 AI) — "왜 이 결과를 예측했는가"를 넘어, "왜 다른 결과는 예측하지 않았는가"라는 반사실적(counterfactual) 설명에 관심이 많습니다.
- LLM & Hallucination 완화 — 졸업 작품을 준비하며 RAG의 한계(검색 단계에서 근거를 못 찾거나, 찾은 근거를 답변에 제대로 반영하지 못하는 문제 등)를 직접 확인하고, 이를 개선하는 방향을 고민하고 있습니다.
