## 안녕하세요, 문예은입니다

한국어 건강뉴스를 읽으며 ‘기사를 통해 잘못된 건강정보가 퍼지는 일을 어떻게 줄일 수 있을까?’라는 궁금증이 생겼습니다. 이 질문에서 출발해 기사 속 주장을 의학 문헌과 대조하는 방법을 연구하고 있습니다.

**KoMed-RAG · MediFact** 연구에서 춘계 설계 논문과 추계 논문 모두 제1저자를 맡았습니다. 춘계에는 기사의 과장된 표현을 분석하고, 의학 문헌이 기사 속 주장을 어디까지 뒷받침하는지 확인하는 구조를 제안했습니다. 추계에는 한국어 기사에 쓰인 의학 용어를 PubMed의 표준 주제어(MeSH)에 연결하는 방법을 다뤘습니다. [춘계학술대회 프로그램 · 포스터 D-13](https://kmms.or.kr/homepage/boardMedia/208846)

## 코드로 볼 수 있는 작업

- **TMTI** · 팀 협업 패턴을 찾는 검색기 두 종류를 18개 질문으로 비교했습니다. 규칙이 이미 패턴을 식별하는 경우에는 해당 ID로 설명을 조회하도록 팀 설계를 바꿨습니다. [검색 프로토타입과 서비스 코드](https://github.com/03OhI/LLM-hackathon-2)
- **산불 영상 탐지** · 직접 학습한 가중치로 먼 연기를 놓친 장면을 살펴봤습니다. 한 공개 영상의 같은 프레임에서는 연기 부근을 4배 확대하자 신뢰도 0.53의 검출 상자가 생겼습니다. [모델 가중치와 시연 코드](https://github.com/03OhI/wildfire-detection)
- **지식그래프 임베딩** · 같은 Nations 데이터에서 TransE·RotatE·ComplEx가 주어진 관계에서 빠진 개체를 얼마나 잘 예측하는지 MRR과 Hits@10으로 비교했습니다. [실험 기록](https://github.com/03OhI/knowledge-graph-embedding)
